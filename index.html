메리세이프가 하는 일

반갑습니다. 메리세이프 현장 스텝으로 함께해 주셔서 고맙습니다.

저희가 하는 일은 간단합니다. 결혼식에 오신 하객분들이 축의금을 내시면 저희가 대신 받아 드립니다. 봉투를 받아 하나씩 적어 두고, 식권을 챙겨 드리고, 예식이 끝날 때까지 안전하게 지키고 있다가, 신랑·신부님이 미리 정해 두신 분께 한 번에 전해 드립니다.

받는다 → 적는다 → 지킨다 → 넘긴다

이 네 가지가 전부입니다. 어려운 일은 아니에요. 다만 저희가 맡는 것이 남의 소중한 돈이고, 결혼식은 그날 한 번뿐입니다. 신랑·신부님 입장에서는 가장 마음 쓰이는 일을 처음 뵙는 저희에게 맡기시는 거예요.

그 믿음에 답하는 방법은 하나, 적어 두는 것입니다. 접수대는 도착부터 인계까지 카메라 2대로 촬영되고, 봉투마다 번호와 금액이 남습니다. 나중에 어떤 질문을 받아도 기록으로 답할 수 있게요.

하루가 이렇게 흘러갑니다

각 줄을 누르면 해당 장으로 갑니다.

이것만 외워 주세요

원칙 1

기억하지 말고 기록한다

"이따 적어야지"는 반드시 잊는다. 적기 전에는 다음 손님을 받지 않는다.

원칙 2

혼자 확정하지 않는다

돈과 숫자는 한 사람이 적고, 다른 사람이 확인한다.

원칙 3

급할 게 전혀 없다

손님이 몰려도 내 순서와 속도를 그대로 유지한다. 서두르다 틀리는 것이 사고다.

절대 금지 — 예외 없음
봉투를 시야 밖에 두기자리 뜨면 동행 스텝에게 인계, 접수 잠시 보류.
지정 안 된 사람에게 인계혼주도, 신랑·신부 본인도 안 됨.
암산권종 수량만 입력. 금액은 시트가 계산.
라이브 임의 종료인계 끝까지. 끊기면 즉시 복구 + 보고.

나머지는 외우지 않으셔도 됩니다. 이 문서에 순서대로 적혀 있으니 필요할 때 찾아보시면 돼요. 혼자 하시는 일이 아닙니다. 늘 두 사람이 함께하고, 애매하면 바로 단톡방에 물어보시면 됩니다. 급할 것 없어요. 순서대로만 하시면 됩니다.

01

예식 전

전날 · 출발 직전
배정 정보
준비물
  1. 01

    전날 — 배정 정보를 받는다. 하나라도 없으면 바로 단톡방에 요청.

    • 예식장·홀 · 예식 시간 (도착 90분 전)
    • 담당 측 · 동행 스텝·역할
    • 인수인계자 1·2순위 이름·관계·연락처 + 비상 연락자
    • 시트 링크 · 라이브 링크 2개
    • 식권 배부 기준 · 계좌이체 응대 기준 · 특별 요청
  2. 02

    출발 직전 — 챙긴다.

    • 키트 — 촬영 폰 2 · 스탠드 2 · 보조배터리 · 케이블·멀티탭 / 노트북 · 와이파이 에그 / 검은 볼펜(메인)·파란 볼펜(서브) 각 2 · 종이 백업 양식 / 계수기 · 고무줄 · 스테이플러+심 / 투명 케이스 · 비밀번호 케이스 / "보안 촬영 중" 안내판
    • 촬영 폰 2대 · 개인 폰 · 노트북 완충 · 촬영 폰 여유 10GB+
    • 셔츠 + 정장 · 단정한 머리 · 낮은 검정 구두
    • 도착 시각 동행 스텝에게 공유

    주차 = 예식장 하객 주차. 주차비 개인 부담 없음.

02

도착과 세팅

−90분 도착 · −60분 완료
현장 파악
카메라
식권
  1. 01

    현장을 파악한다 — 서브, 도착 즉시. 8가지를 확인해 메인에게 공유.

    • 화장실
    • ATM
    • 주차 정산 방법
    • 연회장 · 식사 시작 시간
    • 식권 추가 구매 창구
    • 접수대 사용 가능 시간
    • 정산실 — 없으면 대체 장소 미리
    • 방명록 · 예비 봉투 — 없으면 안내데스크
  2. 02

    카메라 2대를 세운다 — 서브가 설치, 메인이 화면 확인.

    • 1번 — 메인 → 서브 방향, 광각. 접수대 전체.
    • 2번 — 책상 위, 현금이 놓이는 지점(메인의 계수 구역) 근접. 봉투를 열고 권종을 세는 손이 프레임에 들어오는지 메인이 직접 화면으로 확인한다. 서브의 식권 배부는 1번 광각이 담는다.

    2대 모두 유튜브 라이브 시작 + 방해금지 모드.

    진행 조건메인이 노트북에서 두 링크를 열어 ①실제 화면이 나오는지 ②제목이 오늘·이 커플·맞는 측인지 ③공개 상태가 "일부공개"인지 셋 다 확인. 하나라도 아니면 접수를 시작하지 않는다.
    전체공개로 켜져 있으면

    즉시 일부공개(링크가 있는 사용자)로 변경 + 단톡방 [긴급]. 하객 얼굴·성함·금액이 검색되는 상태다. 영상을 임의로 삭제하지 않는다.

    • 인터넷 불가 — 와이파이 → 에그 → 핫스팟. 모두 불가 시 기기 녹화(최소 화질, 방해금지) + 단톡방 보고. 영상은 예식 후 회사 전달 → 확인 후 삭제.
    • 앞 예식이 접수대 사용 중 — 구석에서 세팅 완료, 비면 즉시 이동.
  3. 03

    접수대를 차린다 — 메인은 노트북·시트, 서브는 안내판·볼펜·배터리.

    • 노트북 — 오늘 예식 시트. 상단 날짜·고객명·홀·시간 확인
    • 개인 폰(메인) — 웹프로그램(staff.marrysafe.co.kr) 로그인, 해당 예식
    • "보안 촬영 중" 안내판 — 하객이 보는 위치
    • 검은 볼펜(메인) · 파란 볼펜(서브) · 고무줄 · 계수기 · 투명 케이스
    • 보조배터리 → 카메라 2대
  4. 04

    식권을 받는다 — 둘이 함께 세고, 메인이 Step 1 입력·서명받기.

    전달자 앞에서 세고, 수량을 소리 내어 확인.

    말하기성인 100매, 유아 30매 맞으시죠?
    • 웹프로그램 Step 1 입력 + 전달자 서명. 담당 측 탭 → 성인·유아 → 전달자 → 서명 → [수령 확인]. 추가 수령도 Step 1에.
    • 시트 식권 현황에도 같은 수량. (시트 "어린이" = 유아)

접점 3곳 — 상대 역할은 이것만

① 파란 숫자 — 서브가 기재한 값을 메인이 그대로 시트에 입력. 명확히 기재하고, 판독이 어려우면 서브에게 확인.

② 번호 — 봉투 좌상단 번호 = 시트 줄 번호. 한 번 어긋나면 이후 전부 어긋남.

③ 검수 — 계수한 사람은 자기 실수를 발견하기 어려움. 그래서 서브가 검수.

상대 스텝이 밀릴 때 — 해도 되는 것
  • 메인 처리가 지연될 때 → 서브는 평소대로 수령해 순서대로 쌓아 전달. 하객 대기 안내는 서브가.
  • 서브가 하객 응대에 묶일 때 → 메인이 방명록 작성 안내 정도는 대신. 파란 볼펜 기재는 식권을 배부한 사람만.
  • 상대 스텝이 적은 번호·수량·금액이 이상해 보이면 그 자리에서 말하기.
하면 안 되는 것
  • 상대 스텝의 시트에 대신 입력
  • 볼펜 색 바꿔 쓰기 — 파랑 = 서브, 검정 = 메인
  • 번호 미리 매기기
  • 혼자 두 역할 — 자리 뜨면 봉투 인계 + 접수 보류

서브 — 접어둠수령 → 방명록 작성 안내 → 현금 유무 확인 → 식권 수량 확인 → 파란 볼펜으로 먼저 기재 후 식권 배부.

서브 5동작

  1. 01

    수령. 두 손으로, 가벼운 인사. 한자 이름은 성함을 여쭤 한글 병기.

  2. 02

    방명록 작성 안내.

    말하기방명록에 성함 남겨주시면 감사하겠습니다.
  3. 03

    현금 유무만 확인. 하객 앞에서 계수하지 않음.

  4. 04

    식권 수량 확인.

    말하기식권 몇 장 드릴까요? 아이 있으시면 유아 식권도 드립니다.
  5. 05

    봉투 우측 상단에 파란 볼펜으로 먼저 기재 → 식권 배부. 미배부 시에도 0. 예: 성2 / 유1

    순서 고정

    배부 후 기재하면 누락된다 — 실제 사고 사례. 기재 전에는 식권을 배부하지 않는다.

메인 — 접어둠권종·장수 → 시트 입력(암산 금지) → 봉투 좌상단 번호·우측 하단 금액(검은 볼펜) → 20개씩 묶어 보관.

메인 진행 절차 (5단계)

  1. 01

    수령. 받은 순서대로 한 방향으로 쌓고, 먼저 온 것부터 처리.

  2. 02

    권종·장수 확인. 현금은 봉투에서 꺼내지 않음.

  3. 03

    시트 입력. 번호 → 성함 → 성인·유아 식권(파란 숫자) → 5만원권 장수 → 1만원권 장수.

    암산 금지

    장수만 입력. 50만을 30만으로, 5만원권을 1만원권 칸에 — 실제 사고 사례.

  4. 04

    봉투 기재(검은 볼펜). 좌상단 ○ 안 번호, 우측 하단 시트 금액(예: 20만).

    진행 조건봉투 번호·금액 = 시트 해당 줄. 확인 전에는 다음 봉투를 받지 않음.
  5. 05

    순서대로 보관. 20개마다 고무줄로 묶어 서랍에. 묶기 전 번호 연속 여부 확인. 마감 시 20개 미만도 묶음.

접수 중 상시 확인

  • 서브 — 카메라 배터리·화각
  • 메인 — 라이브 실제 화면을 노트북에서 확인 (폰의 "라이브 중" 표시만으로 판단하지 않음)
  • 메인 — 시트 상단 검증 셀. 불일치 표시 → 그 시점 근처에 오류
